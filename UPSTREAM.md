The baseline commit is an unmodified import of the TightVNC 2.8.88 GPL source tree, plus the repository README that existed before the import. Later commits contain the NEC interoperability changes.

The fork intentionally limits its functional delta to Tight UnixLogin authentication, transient full-length credentials, MD5-gated file-transfer resume, project/resource manifests, and release documentation. It does not identify NEC by hostname, port, desktop name, or banner.
